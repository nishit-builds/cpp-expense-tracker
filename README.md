# 💰 C++ Expense Tracker

A menu-driven Expense Tracker application built using C++. This project helps users manage their expenses, search records, and calculate total spending using a simple console interface.

## ✨ Features

- ➕ Add new expenses with a name, category, and amount
- 📋 View all recorded expenses
- 🔍 Search expenses by name or category
- 🧮 Calculate total spending
- 🗑️ Delete expenses by ID
- 💾 Save and load expenses using file handling
- ✅ Validate user input
- ⚠️ Handle file errors and invalid records

## 🛠️ Technologies Used

- C++
- Structures (`struct`)
- Vectors (`vector`)
- Functions
- File handling (`ifstream`, `ofstream`)
- Input validation
- Switch statements and loops

## 📁 File Structure

- `main.cpp` — Main source code
- `expenses.txt` — Stores expense records and is created when the program runs, if the environment permits

## ▶️ How to Run

1. Download or clone this repository.
2. Open `main.cpp` in a C++ compiler or IDE.
3. Compile and run the program.
4. Use the menu to add, view, search, or delete expenses.

## 💾 File Handling

The program uses `expenses.txt` to store expense records. When the application starts, it loads previously saved records. When an expense is added or deleted, the program updates the file.

**Note:** Keep `expenses.txt` in the program's working directory so the application can access it.
